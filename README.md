# Soapbox for Ferdium

[Soapbox](https://docs.soapbox.pub/soapbox/) is an alternative frontend for Mastodon/Pleroma.

To use this recipe, simply enter the URL of your instance's Soapbox installation in the field "Custom server". 
I also recommend either enabling "Use service favicon" or uploading a custom icon, especially if you use several Soapbox instances. 

Should also work with recent forks such as [Nicolium](https://nicolium.app/).
